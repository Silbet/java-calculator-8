# java-calculator-precourse

## 문자열 계산기

구분자와 숫자가 포함된 문자열을 입력하면 구분자를 기준으로 분리해 숫자를 더하는 프로그램입니다.  
사용자가 커스텀 구분자를 추가할 수 있습니다.

## 실행 방법

1. 프로그램을 실행한다.
2. 구분자와 숫자가 포함된 문자열을 입력한다.  
   2-1) 커스텀 구분자를 포함할 수도 있다.

### 예시

입력: “4,5:6”  
출력: “결과 : 15”

입력: “//@\n1@2:3”  
출력: “결과 : 6”

## 구현할 기능 목록

1. 문자열 입력 받기
    - 사용자가 입력한 문자열을 입력받는다.
    - 문자열 입력은  
      **빈문자열** (””)  
      **숫자** (3)  
      **구분자를 갖는 숫자** (1,2) (2:3)  
      **커스텀 구분자를 갖는 숫자** (//;\n1;2) (//;\n1)  
      가 가능하다.
2. 커스텀 구분자 추가하기
    - 기본 구분자(쉼표, 콜론)외에 커스텀 구분자를 추가할 수 있다.
    - 추가하는 방법은 다음과 같다.
        1) 전체 문자열 앞에 ‘//’로 시작하고 ‘\n’으로 끝나는 문자열을 입력한다.
        2) ’//’와 ‘\n’ 사이에 커스텀 구분자가 위치된다.
        3) 커스텀 구분자는 1개만 입력 가능하다.
3. 문자열에서 숫자 추출하기
    - 전달된 문자열에서 구분자를 기준으로 숫자를 추출한다.
    - 구분자는 1개 이상 사용이 가능하다. (e.g. 1,2:3, //@\n1,2@3)
4. 예외 처리하기
    - 사용자가 잘못된 값을 입력한 경우`IllegalArgumentException` 을 발생시키고 애플리케이션을 종료한다.
    - 예외 발생 상황은 다음과 같다.
    - 구분자와 양수 외의 문자를 사용한 경우 (특히 0)
    - 커스텀 구분자의 양식이 맞지 않는 경우 (//로 시작, \n으로 끝. 커스텀 구분자는 숫자가 아닌 문자)
5. 숫자 더하기
    - 추출된 숫자를 더한다.
6. 출력하기
    - 계산한 결과를 ‘결과 : {sum}’ 형식으로 출력한다.
